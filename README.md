# 桌面便签

贴在桌面上的任务便签：随手记下要做的事，做完划掉，晚上直接复制出当天日报。所有记录以 Markdown 文件保存，不用这个程序也能直接打开查看。

Windows 11 上做的，用 .NET 10 + WPF。便签会固定在桌面层：普通程序都盖在它上面，桌面在它下面，点空白处也不会被挡。

| 待办：没做完的一直留着 | 完成：按天分组，可复制那天的日报 |
| --- | --- |
| ![待办视图](docs/images/pending.png) | ![完成视图](docs/images/done.png) |

## 功能

- **三个视图**：待办 / 完成 / 全部。待办里所有未完成的跨天保留，并标明「昨天留下」「2 天前留下」。
- **随手记录**：主窗口输入框回车即存；在别的程序里按 `Ctrl+Alt+N` 弹出小窗，写完回车关闭。
- **完成留痕**：勾选时记录实际完成时间，完成视图按天分组，每组可单独复制那天日报。
- **半透明外观**：能透出桌面壁纸，透明度可在 `···` 菜单里循环切换。
- **整块面板都能拖动**（输入框、按钮和任务列表除外），鼠标移到可拖区域会变成“移动”光标，标题下有一条细分隔线标示；右下角 `◢` 调整大小，位置和大小自动记住。
- **数据是 Markdown**：就能用记事本打开、搜索、迁移；程序不在也能读。
- **桌面层常驻**：不抢焦点，开机后就在桌面上；托盘图标可随时呼出或退出。
- **不怕写坏**：写入用临时文件原子替换，自动保留历史版本，外部改动与程序改动冲突时拒绝覆盖而不是静默丢弃。

## 便携与依赖

- **不需要装 .NET**。发布包是自包含的，`coreclr.dll`、`PresentationFramework.dll` 等运行时文件就摆在 `DeskNotes.exe` 旁边。
- **不占临时目录**。没有打包成单文件，启动时不会把运行时解压到 `%TEMP%`，启动更快，也不怕临时目录被清理。
- **整个文件夹可以搬走**。复制到另一台电脑直接能用，设置和记录跟着走；程序不写注册表。
- **数据就在程序旁边**：`config\settings.json` 和 `data\records\*.md`。
- 目标系统：Windows 11、Windows 10 1607 及以上（x64）。需要说明的是，微软现在的 .NET 支持列表里 Windows 10 只列了 Enterprise / IoT 版（消费版 Win10 已停止支持），所以在家庭版/专业版 Win10 上一般能跑，但不在官方支持范围内。

## 快速开始

从 [Releases](../../releases) 下载 `DeskNotes-win-x64.zip`，解压后直接运行 `DeskNotes.exe`，不需要另外安装 .NET。程序会在自己旁边生成 `config\` 和 `data\`。

也可以自己构建（需要 .NET 10 SDK）：

```powershell
.\build.ps1 -Run
```

第一步会运行存储测试，然后把程序打包到 `dist\DeskNotes.exe` 并启动。`dist` 目录可以直接复制到其他电脑运行，不需要另外安装 .NET。

开发时也可以直接运行：

```powershell
.\build.ps1 -SkipTests
.\dist\DeskNotes.exe
```

## 日常用法

主窗口分成三个视图，用上方按钮切换：

- **待办**：所有没完成的事都留在这里，不分日期。今天没做完的，明天还在，并标明是「昨天留下」还是「3 天前留下」。
- **完成**：按天分组，显示每天完成了什么，每组右边有「复制这天」，可以直接生成那天的日报。
- **全部**：待办和完成一起显示。

在主窗口输入框写一句任务，按回车就保存。想到事情但正在别的软件里，按 `Ctrl+Alt+N` 弹出小窗口，写完回车保存，弹窗关闭。

点复选框完成任务，程序会记录实际完成时间。点任务文字可以编辑标题，也可以写一段“备注 / 实际成果”，这段内容会进入日报。底部“复制今天日报”会打开当天日报，可以修改后复制成 Markdown。

便签是半透明的，能看到一点桌面壁纸。`···` 菜单里的**透明度**可以循环切换（100% → 94% → 86% → 76% → 60%）。右下角的 `◢` 可以拖动调整大小，位置和大小会自动记住。

右上角 `···` 还有其他操作：回收区、打开 Markdown 文件夹、导出全部记录、切换记录目录、透明度、字号、贴在桌面或切回普通窗口、隐藏到托盘、退出。双击托盘图标等于快捷记录。

## 记录存在哪

设置和记录都放在**程序所在的目录**里，和 `DeskNotes.exe` 并排，所以数据在哪一目了然，整个文件夹可以直接拷走：

```
dist/
├─ DeskNotes.exe
├─ config/
│  └─ settings.json   窗口位置、字号、透明度等设置
└─ data/
   ├─ records/
   │  └─ 2026-10.md    每个月一个文件
   └─ backups/         自动保留的历史版本
```

第一次运行这个版本时，如果发现旧位置（`%LOCALAPPDATA%\DeskNotes`）里有记录，会把它们复制到 `data\` 并保留原文件。只有当程序目录不可写（比如放在 Program Files 或只读介质上）时，才会退回原来的用户目录。

注意：因为数据就在程序旁边，**不要单独删除 `dist` 文件夹**，那会连记录一起删掉。重建时可以只覆盖 `DeskNotes.exe`。

Markdown 里每个任务长这样：

```markdown
## 2026-10-03
<!-- desknote:{"id":"...","created":"...","completed":null,"deleted":null,"isCompleted":false} -->
- [ ] 给 Git 文档工具加搜索
  先支持按标题搜索。
<!-- /desknote -->
```

标题、复选框和备注是普通 Markdown，可以直接手改；两个 HTML 注释保存编号和时间，请不要删除。直接手改文件后，程序会在两秒内自动刷新。想手动加任务，写一行 `- [ ] 内容` 也能被识别。

如果手动把 `- [ ]` 改成 `- [x]` 但没有填完成时间，程序会把它放进“完成日期待确认”，不会猜一个时间写进日报。

## 关于贴在桌面

便签保持普通窗口，但会固定到窗口层叠顺序的最底部，所以效果是：**普通程序都盖在它上面，桌面在它下面**。它不会抢焦点，程序启动时也不会打断你正在做的事。

早期版本尝试用 `SetParent` 把窗口挂成桌面窗口的子窗口，实测在 Windows 11 上这条路走不通：窗口报告“可见”但完全不绘制，而且子窗口拿不到键盘焦点，便签上打不了字。现在的做法不改父子关系，只固定层级，因此显示和输入都正常。

窗口被隐藏时（例如按了显示桌面）程序会自动把它重新显示出来。如果你不希望它常驻桌面，`···` 菜单里可以随时切换成普通窗口。

## 开发

实现细节、踩过的坑和验证记录见 [docs/VERIFICATION.md](docs/VERIFICATION.md)，其中记录了为什么不能用 `SetParent` 挂到桌面窗口（在 Windows 11 上不绘制，且子窗口拿不到键盘焦点），以及「显示桌面」后便签消失的原因和修法。

程序图标由 `tools/icon/` 生成，字形取自 Windows 自带的 Segoe Fluent Icons 图标字体（`E73D`，微软复选样式），矢量绘制以保证 16px 下清晰。

### 已知限制

- 全屏游戏会盖住便签，退出全屏后自动恢复。
- 多显示器与改变缩放比例后的位置尚未验证。
- 只支持 Windows。

```
src/DeskNotes.Core   任务模型、Markdown 读写、日报生成
src/DeskNotes.App    WPF 界面、桌面挂载、托盘、全局快捷键
tests/DeskNotes.Tests 存储与日报的结算测试
```

```powershell
.\.dotnet\dotnet.exe run --project tests\DeskNotes.Tests -c Release
```

界面自检（不写入正式记录，截图输出到 `work\preview-<视图>.png`）：

```powershell
.\.dotnet\dotnet.exe run --project src\DeskNotes.App -c Release -- --preview
```
