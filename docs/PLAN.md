# 实施计划

1. 初始化 Git、WPF 项目和 Markdown 核心。
2. 实现桌面挂载、托盘、全局快捷键、便签 UI。
3. 接入新增、编辑、完成、回收、搜索、历史和日报。
4. 验证 Markdown 保留、冲突检测、原子保存、跨天统计。
5. 构建便携版本、启动检查并记录已验证与待人工确认事项。

## 桌面模式

Explorer 的桌面宿主不是稳定公开的挂件 API。使用 Shell 窗口查找与 SetParent，定期检查宿主并恢复。失败时退回非置顶普通窗口。Win+D、多屏、Explorer 重启需要真实桌面验收。

## 第一版边界

支持单机本地 Markdown、快捷记录、历史搜索、日报、回收恢复。暂不支持云同步、AI 润色、附件和提醒。直接编辑 Markdown 支持标准任务行和应用备注格式；外部完成时间缺失时显示待确认。
