# 实施计划

1. 初始化 Git、WPF 项目和 Markdown 核心。
2. 实现便签 UI、托盘、全局快捷键。
3. 实现桌面层固定（不改父子关系，固定到层叠顺序底部）。
4. 接入新增、编辑、完成、回收、搜索、历史和日报。
5. 验证 Markdown 保留、冲突检测、原子保存、跨天统计。
6. 构建便携版本并记录已验证与待人工确认事项。

## 桌面层固定

先用 `SetParent` 挂到 `Progman` 子窗口，实测在 Windows 11 26100 上不绘制且无法接收键盘焦点（详见 `VERIFICATION.md`）。改为保持普通顶层窗口，固定到层叠顺序最底部：普通程序覆盖它，桌面在其下方，并定期重新固定；窗口被隐藏（显示桌面）时重新显示。

## 第一版边界

支持单机本地 Markdown、快捷记录、历史搜索、日报、回收恢复。暂不支持云同步、AI 润色、附件和提醒。直接编辑 Markdown 支持标准任务行和应用备注格式；外部完成时间缺失时显示待确认。
