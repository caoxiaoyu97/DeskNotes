# 验证记录

## 桌面挂载的重大修正

第一版把便签用 `SetParent` 挂到资源管理器桌面窗口（`Progman`）下。实测在本机 Windows 11（内部版本 26100）上这条路走不通：

- 窗口被报告为 `IsWindowVisible = true`，位于 `Progman` 子窗口最上层（`SHELLDLL_DefView` 之上），但屏幕上完全不绘制，只透出壁纸。
- WPF 与 WinForms 表现相同，因此不是 WPF 绘制方式的问题。
- 附带问题更严重：子窗口无法获得键盘焦点，便签上根本打不了字。

对照实验（同一张截图内三个窗口）：

| 方式 | 结果 |
| --- | --- |
| 顶层窗口 + `SetWindowPos(HWND_BOTTOM)` | 正常显示 |
| 顶层窗口 + 插到 `Progman` 之后 | 正常显示 |
| `SetParent` 到 `Progman` 子窗口 | 报告可见，实际不绘制 |

因此改为**不改变父子关系**：便签保持普通顶层窗口，固定到层叠顺序最底部。普通程序都在它上面，桌面在它下面，输入功能保持正常。
