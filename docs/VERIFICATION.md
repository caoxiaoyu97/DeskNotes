# 验证记录

## 已在本机验证

- 中文任务标题输入、回车保存、列表即时更新。
- 勾选完成写入完成时间，取消完成清空完成时间。
- 关闭后重新启动，任务从 Markdown 恢复。
- `Ctrl+Alt+N` 弹出快捷记录窗口，回车保存后关闭，内容进入待办。
- 托盘菜单、日报预览、搜索、日期回看、回收区可打开。
- 存储测试 10 组通过：中文与多行备注往返、外部编辑保留、冲突拒绝、重复编号拒绝、备份保留上限、日报按实际完成日统计、可读元数据转义、外部勾选变化清除过期完成时间、按天标题与本地日期导入、每月备份隔离。

以上界面操作通过 Windows 辅助功能接口与截图确认，测试数据使用 `work/preview-data`，不会写入正式记录。

## 需要人工确认

- Win+D 显示桌面后便签是否仍然可见。
- 多显示器、改变缩放比例后便签位置是否正确。
- 资源管理器重启后是否自动回到桌面层。
- 不同 Windows 版本下桌面挂载是否稳定。

这些依赖资源管理器的桌面层级，代码已做轮询与事件恢复，但没有稳定的公开接口，无法在不影响你日常使用的前提下自动验证。
